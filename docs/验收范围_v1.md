# 留白 0.1.0 验收范围

本次按用户需求、实际功能与交付声明建立验收清单。浏览器测试对应 APK 内的同一套 HTML/CSS/JS；模拟原生桥不等于真机测试或真实大模型服务成功。

| 功能 | 功能检查 | 视觉检查 |
| --- | --- | --- |
| 免登录每日首页 | 无账号门槛，同日选句稳定，换日刷新，收藏去重，AI生成状态 | 320/360/393/480像素、暖白与夜间 |
| 情绪记录 | 五种心情、保存、修改、七天足迹、删除 | 首页选择态、空状态 |
| 随手记/小行动 | 新建、编辑、搜索、完成、删除确认、重启保留 | 长内容换行、底部操作不遮挡 |
| AI原生对话 | 三种模式、连续追问、重试、停止、会话历史、模型切换 | 流式正文、错误、来源、可确认操作 |
| 模型配置 | 三服务商、Key不回显、浏览器禁收Key、移除、错误反馈 | 配置面板、无Key状态 |
| 联网搜索 | 默认关闭、独立搜索服务、来源跳转、失败不假装成功 | 开关状态与来源卡片 |
| 数据管理 | 偏好编辑、主题持久化、Markdown导出、清除确认 | 设置和确认弹层 |

额外边界检查包括模型返回HTML注入、损坏操作JSON、断流、只返回思考无正文、跨日、无效接口、重定向泄漏、存储空间不足。

真机待验证：APK安装、Android Keystore读写、原生桥、软键盘、系统返回、系统文件选择器、服务商账号权限与实网连接。本版首页每日更新，不含系统通知推送；小行动不设置闹钟。
