# 留白隐私说明 v1

留白0.1.0无需注册账号，没有自建中转服务器、广告SDK、统计SDK或自动云同步。

API Key由Android Keystore配合AES-GCM加密保存在应用私有存储，不回显，不写入网页存储或导出。生活记录、相处偏好与对话保存在手机WebView本机存储，未额外加密；已禁用Android自动备份。

模型调用将当前对话、相处偏好、设备日期和今日心情直接发送给用户选定的模型服务商；不会自动发送收纳库或其他会话。开启联网搜索时，当前问题开头最多120个Unicode字符作为搜索词发给搜索服务商，搜索摘要再交给模型。适用各服务商的数据处理条款和计费规则。

只有INTERNET权限，不读取通讯录、位置、相册、麦克风或设备上的其他应用数据。文件导出由用户通过系统文件选择器发起。

卸载、清除应用数据或设备损坏可能导致记录丢失，请先导出。导出为Markdown用于阅读归档，当前不支持一键导回。清除生活记录不会移除密钥，密钥需在各模型配置中单独移除。

本版尚未完成真实Key与真机联调。源码公开便于核查，本声明描述当前实现，不代表已接受独立隐私审计。
