# 留白使用说明 v1

留白是一个免登录的安卓个人生活助手。应用名取“给生活和自己留一点空隙”的意思，采用你选择的暖白墨绿，重点是情绪陪伴与自我整理。

## 安装后先试这几件事

安装 `Liubai_0.1.0_preview.apk`，无需注册。首页每天有一句原创感悟，在五个心情表情中选一个，即可记下今天。往下滑可进入梳理、随手记或晚间复盘。

未配置模型，也能看每日一句、收藏、记心情、写随手记和安排小行动；这些内容保存在手机。

## 配置模型

进入“我的”，找到DeepSeek、Kimi、GLM，选择“配置”。填写该开放平台的API Key，检查完整HTTPS对话接口和模型ID，然后点“加密保存”。密钥不回显；再次保存时留空表示保留旧密钥，修改接口地址则需重新填写。

预设使用DeepSeek deepseek-flash、Kimi kimi-k3、GLM glm-5.3，模型ID可改为自己账号可用的模型。会员订阅或Coding Plan不一定能用于标准API。相应模型和搜索权限、余额需由服务商提供，应用没有内置额度。

首次发送一句“你好，想和你聊聊今天”，看到真实回答即可确认当前配置可用。“密钥已保存”只说明本机存储成功。报401/403先核对密钥和权限，报404核对接口与模型，报429检查额度或稍后手动重试。

## 自然地说话

“听你说”偏向倾诉；“一起梳理”帮助区分处境、感受和可控部分；“晚间复盘”帮你看见一天的经历。它们不是心理诊断或人格测评。

模型给出的随手记、小行动卡片不会自动执行。点“确认收下”才保存；收纳页还可以再编辑。小行动不带系统提醒。模型输出可能有误，实时事实请核查来源。

生成中可点输入框右侧方块停止；未完成内容会明确标记。失败可点“重新回应”。“新聊”保留旧对话并开启新的上下文，在“过往对话”中可以恢复或删除。

## 每日一句与联网

默认每日一句使用31段离线原创选句，按手机本地日期轮换。爱心收藏，复制按钮复制，右侧刷新按钮让当前模型为你写一句，会产生一次模型调用。

“我的”里可启用“每天打开时，AI写一句给我”。开启后，已配置模型时每日首次打开自动请求一次，关闭后台后不会主动推送通知。同一天已生成的内容会缓存，不重复自动请求；失败保留离线句子，不自动重试。需要重试可手动点击刷新。

输入框下的联网搜索默认关闭，倾诉时不必开启。需要公开资料时打开，当前问题会被作为搜索词发给搜索服务商，搜索摘要随后发送给对话模型。来源可以点开核查。你可以单独选择另一家已配置的搜索服务，与当前陪伴模型组合。使用自定义对话接口时，需另选已配置官方接口的搜索服务。

## 留住自己的记录

“收纳”里分别查看随手记、小行动、收藏句子和心情足迹。可以搜索、修改、删除，删除前会再次确认。

“我的 → 导出生活记录”通过系统文件保存入口导出Markdown，可用文本或笔记软件阅读。卸载前务必导出；目前不提供导回。记录没有云同步，没有跨设备账号。导出含私人记录，请自行保管。密钥不进入导出文件。

这是0.1.0个人预览版，支持Android8.0及以上，需近期Android System WebView。已通过本机协议和浏览器交互检查、APK编译与签名校验；尚未连接安卓真机，也未使用真实API Key验证各服务商账号权限。

本版包含首页每日更新，不包含系统通知推送、语音、闹钟、日历、定位或附件上传。[公开源码](https://github.com/taonian1989-hub/liubai-android)。
