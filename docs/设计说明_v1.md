# 留白设计说明 v1

已确认偏好：暖白墨绿，安静有质感；情绪陪伴与自我整理优先。

首页把每日一句放在第一视线，结合本地日期、克制的时间问候与心情表情。底部输入框跨首页和聊天页常驻，从“想到什么，就说说”直接进入对话。收纳和设置页隐藏输入框，保证管理记录时有足够空间。

四个导航为今天、聊聊、收纳、我的。首页不加入统计打分、连续打卡、强制目标或人格结论。三种对话方式帮助改变回应重点，无需用户学习提示词。梳理与晚间复盘入口先填好一个起始问题，由用户修改并发送，避免点击模板直接扣费。

AI回答采用自然文本与来源卡片。可选建议块仅限note、task两类，单项最多180字、最多两项，解析失败就忽略建议；用户确认后才写入存储，不执行任意工具或日历操作。模型正文与用户内容都按纯文本显示。

颜色使用暖白#F7F7F2、墨绿#294F46、淡绿灰#E9EDE4。每日句子采用本机可用的衬线字体，其他内容使用系统无衬线。无需远程字体或图片，离线可用。首页细线圆环与应用标记由CSS/Android矢量资源构成。夜间外观同步原生背景和系统栏图标。

个性化来自用户编辑的偏好、当前会话与当日心情。INFJ、星座与血型只是用户自我认同，不推断人格。生活记录不被默认塞进提示词，不自动读取其他会话。

交互界面封装在原生Android受限WebView，原生层负责HTTPS、流式生成、Android Keystore与系统文件导出；没有自建账户或中转服务。这样可在当前环境中构建独立APK，同时保持离线页面与可测试的交互。
